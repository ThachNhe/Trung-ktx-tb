end

' ── UC6 | Biểu đồ tuần tự ────────────────────────────────
@startuml UC6_Duyet_Don_Dang_Ky_Sequence
title UC6 – Duyệt đơn đăng ký 

actor       "Nhân viên"     as NV
participant "Giao diện"     as UI
participant "Backend API"   as API
database    "Cơ sở dữ liệu" as DB

NV  -> UI   : Xem danh sách đơn PENDING
UI  -> API  : GET /api/v1/registrations?status=PENDING
API -> DB   : Truy vấn đơn
DB --> API  : Danh sách đơn
API --> UI  : Danh sách đơn đăng ký
UI  --> NV  : Hiển thị

NV  -> UI   : Chọn Duyệt / Từ chối
UI  -> API  : PUT /api/v1/registrations/{id}/approve (hoặc /reject)
API -> DB   : Kiểm tra phòng còn chỗ & trạng thái
DB --> API  : Thông tin phòng

alt Phê duyệt
  API -> DB  : UPDATE registration status=APPROVED
  API -> DB  : UPDATE room current_occupancy +1 (và status nếu đầy)
  API -> DB  : INSERT notification cho sinh viên
  DB --> API : OK
  API --> UI : 200 OK – Đã phê duyệt
else Từ chối
  API -> DB  : UPDATE registration status=REJECTED
  API -> DB  : INSERT notification cho sinh viên
  DB --> API : OK
  API --> UI : 200 OK – Đã từ chối
end
UI  --> NV  : Cập nhật danh sách
@enduml

alt Đã thanh toán rồi

  UI  --> SV : Thông báo lỗi
